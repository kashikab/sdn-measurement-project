# Results directory

The dashboard and command-line runner generate current experiment outputs here (`experiments.csv`, `live_telemetry.json`, `last_sender.json`, `last_receiver.json`, and `last_experiment.json`). These files are generated when you run the project and should be retained as final demonstration evidence.

`legacy_d1/` contains screenshots and a sample flow-counter CSV from the earlier single-switch D1 implementation. They are retained for historical reference only; they are not proof of the current three-switch topology, dynamic redirection, or congestion-response behaviour. Re-run the current project and capture fresh screenshots for final submission.
